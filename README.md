"THE WORLD TODAY" — the whole of Wednesday 25 November 2026 on one 1024x1024 newspaper front page, drawn entirely in code. 47 numbered stories with datelines and wire attributions: three large drawn scenes (Kyiv's sea-drone strikes, the WHO Ebola evacuation in Congo, Shenzhou-24's launch), eight pictogram scenes, a six-number stat strip, a region tally bar, a dotted world map with 22 pins numbered to the stories, 36 numbered briefs, a date-check box that names the other days' news left out, and a sources footer. Pure Python 3 stdlib + PIL, fully deterministic — the script regenerates entry.png byte for byte.
